# Zay Shop

A front-end e-commerce demo built on the free **Zay Shop** HTML/CSS template (TemplateMo), extended with a login page, a working cart and product details in JavaScript.

## Pages

`index.html` (home), `shop.html`, `details.html`, `cart.html`, `Login.html`, `Aboutus.html`.

## Features

- Product listing and product details.
- Cart logic in `assets/js/cart.js`.
- Login form with a script in `assets/js/Login.js`.
- Responsive layout with Bootstrap and Font Awesome.
- `_redirects` file for Netlify deploys.

## Run locally

```bash
git clone https://github.com/Ahmedelnmr/Zay-shop.git
cd Zay-shop
npx serve .
```
